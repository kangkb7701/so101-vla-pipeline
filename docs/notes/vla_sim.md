# vla_sim.py 코드 리뷰 및 수정 보고서 (Research-Grade Optimization)

본 보고서는 `evaluation.md`의 고도화된 피드백을 반영하여 연구 수준(Top-tier)으로 최적화된 제어 시스템 명세입니다.

## 1. 고도화된 제어 시스템 상세

### 1.1. 정밀한 액션 스케일링 (Action Scaling)
*   **배경**: VLA 모델의 출력(Delta Pose)은 학습 데이터셋의 단위계에 종속적입니다. 시뮬레이션 환경의 물리 단위(m)와 일치하지 않을 경우 로봇이 너무 느리게 혹은 너무 빠르게 움직일 수 있습니다.
*   **수정**: `ACTION_SCALING_FACTOR`를 도입하여 모델의 출력을 시뮬레이션 환경에 최적화된 크기로 조정했습니다. 이는 시뮬레이션과 실제 로봇 사이의 간극(Sim-to-Real gap)을 줄이는 핵심 파라미터입니다.

### 1.2. 관절 궤적 평활화 (Joint Smoothing & EMA)
*   **배경**: IK 솔루션은 매 프레임 독립적으로 계산되므로, 미세한 수치적 불안정성으로 인해 관절이 미세하게 떨릴 수 있습니다.
*   **수정**: 지수 이동 평균(Exponential Moving Average, EMA) 필터를 적용한 `SMOOTHING_ALPHA` 로직을 구현했습니다. 이를 통해 모델의 고수준 지능은 유지하면서 물리적 움직임은 훨씬 부드럽게 개선되었습니다.

### 1.3. IK Safety Guard 고도화 (Clamping)
*   **배경**: 기존에는 IK 점프 발생 시 단순히 동작을 멈췄으나, 이는 태스크 수행 흐름을 끊을 수 있습니다.
*   **수정**: `np.clip`을 활용하여 급격한 변화가 감지될 때 최대 변화량을 제한(Clamping)하여 안전하면서도 목표에 근접하도록 개선했습니다.

## 2. 좌표계 및 회전 변환 재검토 (Final Opinions)
*   **좌표계**: `R_cam_to_base` 행렬은 카메라 설치 위치에 따라 `T = [R|t]` 형태의 4x4 Homogeneous Transformation으로 확장될 수 있습니다. 현재는 회전 위주로 설계되었습니다.
*   **회전 순서**: `current_rot @ delta_rot` (Local frame) 방식을 채택했습니다. 이는 조종자가 그리퍼 끝단을 기준으로 회전시키는 직관적인 제어 방식을 따릅니다.

## 3. 비동기 추론(Asynchronous)에 대한 제언
현재 시뮬레이션 루프는 **동기식(Sync)**입니다. 실제 로봇 배포 시에는 다음과 같은 구조가 필수적입니다:
1.  **추론 스레드**: 카메라 이미지를 받아 OpenVLA 예측 (0.1~0.5s 소요)
2.  **제어 스레드**: 최신 예측값과 현재 상태를 기반으로 IK를 계산하여 모터에 고속 명령 하달 (100Hz+)
*이 코드는 해당 리팩토링을 위한 모든 제어 로직(IK, Scaling, Smoothing)을 이미 모듈화하여 갖추고 있습니다.*
